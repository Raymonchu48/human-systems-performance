# Human · Systems · Performance

Portfolio profesional interactivo de **Ramón A. Curbalán** que integra tres ámbitos en una única narrativa profesional:

- **Hostelería:** operaciones, eventos, F&B, equipos y experiencia de cliente.
- **Tecnología:** sistemas, desarrollo, automatización, ciberseguridad, datos e IA.
- **Deporte:** entrenamiento, nutrición, rendimiento, hábitos y coaching.

## Concepto

> Tres disciplinas. Una misma forma de pensar.

El proyecto presenta una visión basada en **Personas · Procesos · Tecnología · Rendimiento** y utiliza un cluster interactivo para mostrar cómo las tres áreas se conectan en un único sistema profesional.

## Metodología

**Analizar → Diseñar → Ejecutar → Medir → Mejorar**

## Tecnología

Primera versión construida con HTML5, CSS3 y JavaScript vanilla para maximizar compatibilidad, rendimiento y facilidad de despliegue en GitHub Pages.

## Estado

MVP funcional responsive para escritorio, tablet y móvil.
